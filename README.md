# 潮位报文归集台

港务水文组收到各潮位站的定长报文。归集员把一批报文贴进来，系统按站码和时刻解析、去重，能落库的写入归集表，列数不对、站码坏了或时刻已经存在的行单独列出。

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python FastAPI |
| 页面 | Vue 3，无组件库 |
| 数据库 | PostgreSQL 16 |

## 种子数据

| 批次 | 结果 |
|------|------|
| 吴淞口 11-12 早班 | 三行都已归集 |
| 外高桥 11-12 错报 | 一行新站落库，一行时刻重复，一行站码不合法 |

报文每行四段，用竖线分开：站码、十二位时间、潮位厘米、质量旗。质量旗 A 是实测，M 是插补，B 是可疑。

## 旗争去重

同一站同一时刻若同时来了实测旗 A 和插补旗 M，触发旗争，按当天封存的让位方式裁决，一个争用点只放行一种结局：

- **实测留库、插补让位**：只把实测旗写入归集表，插补旗进落选队列。
- **两行都不入库**：实测、插补都不入库，全部进落选队列。

规则：

- 每批报文先整批解析，实测旗、插补旗都解析完再分组裁决；无法识别的旗（坏行、可疑旗 B）不参与比较。
- 让位方式在「让位设置」里选定后即封存，当天不得更换；换一天可重新封存。
- 批次请求里的让位方式与当天封存不一致，旗争行写「让位方式不符」，且不入库；当天尚未封存则写「让位方式尚未封存」。
- 两批报文同时把实测旗和插补旗送进同一时刻，顺序锁（PostgreSQL 咨询锁）只放行一种结局，后来一批整批评「让位争用」进落选队列。
- 让位写入期间设置锁定，不许改让位设置。

### 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/yield-setting` | 当天让位设置、可选方式、写入锁定状态 |
| PUT | `/api/yield-setting` | 封存当天让位方式（仅归集员，当天一次） |
| GET | `/api/flag-contests` | 旗争列表：留下的旗、落选数、让位次数、方式名 |
| GET | `/api/flag-contests/{id}` | 旗争对照详情：留下与落选两行的厘米对照 |
| GET | `/api/yielded-queue` | 落选队列：未入库的旗逐行留底 |
| POST | `/api/batches` | 归集报文，可带 `yield_method` 声明本批让位方式 |
